# 个人 EDA 设计风格

依据用户指定的五个工程及其明确反馈整理。下面是此用户的默认偏好；当前任务的尺寸、功能、制造和电气约束优先。核对实例或决定是否采用某项条件性做法时，读 [references/design-evidence.md](design-evidence.md)。

## 原理图

- 用横竖分隔线组织功能区，加中文标题，例如“电源输入处理”“主控 MCU”“输出接口”。相邻模块共用分隔线，形成清楚的行列关系；按电路规模分配面积，不强求等大方格。分隔线使用绘图图元，不用电气导线。
- 模块内部尽量直接连线，展开反馈、分压、滤波、保护和驱动链路。网络标签主要连接跨模块、跨页信号及公共电源；芯片与近旁无源器件之间能清楚直连的，不拆成一堆标签。局部导线用横竖折线，避免穿过标题、位号和参数。
- 重复通道使用同一方向、间距和拓扑，按信号编号或电源轨顺序排列。去耦电容阵列在原理图中可整齐成组；PCB 上的对应电容仍应贴近各自供电引脚。
- 保留嘉立创 EDA 原生图框及右下角图纸明细栏。这里的“明细表”指工程、板子、图页、版本、绘制者、日期等标题栏，不能默认替换成器件清单或 BOM。沿用工程实际字段，不虚构审阅人或版本。
- 优先沿用现有 A4/A3 图幅。总标题、模块标题、器件标注形成字号层级；导出后检查中文字体、文字重叠、裁切和明细栏遮挡。不要照搬示例中溢出的巨大标题。
- 通用模块适合在空白区写简短功能说明，如供电范围、输出电压/通道、通信协议、接口和已核实的限制；未经验证的性能不写成承诺。
- 原理图导入 PCB 之前，先清除器件位号，再重新分配位号；核对位号无遗漏、无重复，运行原理图 DRC 并修正问题，通过后再导入。已有 PCB 对应关系时，重新编号后同步核对元件映射。

## PCB

- 板形、定位孔、操作件与连接器先服务于机械安装和实际接线。板框默认采用圆角；圆形板保留圆形轮廓，其他板形的转角采用圆弧过渡，圆角半径按机械尺寸和边缘间距确定，不固定模板。核对板框闭合、圆弧与相邻边衔接。
- 接口靠可接近的板边布置，功能相关器件就近成组，重复通道保持有序、间距协调。允许芯片旋转或双面放置以改善连接路径，不能仅为视觉整齐拉长关键回路。
- 丝印除位号外，强调使用信息：供电电压、正负极、GND、接口引脚名、信号编号和必要的操作名称。复杂控制板背面有空间时，可采用中文功能框，参考循迹小车主板；小板不强塞大段说明。
- 丝印文字的笔画线宽至少 6 mil（0.1524 mm），文字高度至少 45 mil（1.143 mm），位号和接口说明均按此起步。这里的线宽指笔画粗细，不是文字总宽度。空间不足先优化摆放、移动文字或精简说明，不默认缩小到上述下限以下；检查实际属性和双面出图，避免遮挡焊盘或文字重叠。
- PCB 的 GND 默认通过接地铜皮连接，不主动逐点走 GND 导线；跨层连通按需要布置接地过孔。重新铺铜后核对所有 GND 焊盘的实际连接、未连网和孤岛，不能只凭铜皮覆盖就认为已连通。此项是 PCB 布线习惯，原理图仍须正确表达 GND 网络。
- 其他指定由铺铜区域连接的网络也按相同原则处理：铜皮已形成有效连接时，不再添加重复导线。对现有冗余导线，核对移除后铜皮仍满足连通和电气要求；以重新铺铜后的实际结果为准，不把仅有区域轮廓或未连通铜岛当作已连接。
- 逐个检查器件的 GND 焊盘附近是否有就近的 GND 过孔，靠近焊盘根部摆放，缩短接地路径；此处检查对象是器件焊盘，不是已有过孔。非必要不用盘中孔，默认把接地过孔放在焊盘外并满足间距规则。最后的自动缝合孔不能代替这一步局部检查。
- 铜皮连接焊盘默认使用直连模式（Solid），不用发散/热焊盘模式（Thermal Relief）；检查实际铜皮设置与重新铺铜后的结果。
- 先简化走线路径，清除多余小拐点和短碎线段。若小幅调整可移动器件、焊盘朝向或过孔位置就能直连，优先调整布局，把路径整理成干净的直线或少量必要转弯；保留机械固定位置和关键电气约束，不用一串小圆弧掩盖多余折点。
- 走线使用 45°圆弧或 90°圆弧模式，不使用自由角度走线模式；直线段保持所选模式的角度约束，相关走线保持共同方向和协调间距。通过 API 绘制也须符合这些几何约束，不能因圆角处理引入任意角度斜线。
- 简化路径后逐处检查转弯，在间距、阻抗及其他规则允许的范围内实际增大圆弧半径，不停留在默认的小圆角。必要时先调整邻近可移动对象以腾出圆弧空间，避免增加无谓绕行；收尾核对实际圆弧几何半径与局部画面，不能只修改模式就宣称半径已增大。确实无法增大的位置说明具体限制，不虚构统一半径。
- 走线宽度按网络用途、电流、长度、允许压降及铜厚选择，不把所有网络统一设为默认 10 mil。电源输入、输出和功率路径等需要更宽的连接应主动加粗，检查焊盘出口和局部收窄处；信号线仍按其电气要求确定，不为视觉一致强行同宽。
- 根据密度与信号需求选层数。样本同时存在 2、4、6 层板，不能固定为“四层最佳”。AGND/DGND/PGND、专用电源层、隔离槽和分区铜皮都是条件性电路方案，不是通用美化规则。
- GND 缝合孔放置后检查新增孔与已有 GND 过孔之间、以及新增孔之间的距离，适当合并过近且功能重复的孔，由邻近焊盘共用。保留的孔应仍靠近相关焊盘根部，并满足所需跨层连接和回流要求；不能仅按距离删除承担必要接地功能的孔。合并后重新检查局部焊盘接地路径。
- PCB 布局布线及局部 GND 过孔整理完成后，先使用泪滴工具生成泪滴，再重新铺铜，顺序不能颠倒；随后使用 GND 铺铜的“添加缝合孔”功能补一遍 GND 过孔，再检查并合并过近的重复 GND 过孔。确认保留过孔属于 GND 且连接目标铜皮，按需更新受影响连接的泪滴，再次重新铺铜，最后运行 PCB DRC 并修正问题，直到通过。后续修改走线、过孔或铜皮后，重新检查受影响的泪滴、铺铜与连接，并重跑 PCB DRC。

## 完成条件

原理图 DRC 和 PCB DRC 必须都实际运行并通过，才能将整套设计报告为完成。相关设计修改后重新检查，确保结果对应最终版本；不能用关闭检查规则或忽略报错替代通过。若检查无法执行或结果无法确认，如实说明尚未通过验证。

## 用于整理现有设计

先保持器件、引脚号和网络关系，再调整摆放、连线表达及标注。风格整理涉及重画连线时核对网表；分别查看整页、关键局部和 PCB 双面，确认排版与连接都保留。按当前任务指定的工程和窗口操作；本技能不扩大修改范围。
